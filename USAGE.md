# Как пользоваться OhMyPhoto

Открой `/admin.html` в браузере (локально: `http://127.0.0.1:8787/admin.html`, на проде: `https://your-domain/admin.html`).  
Введи `ADMIN_TOKEN` и нажми **Login**.

---

## Разделы (альбомы)

### Создать

1. В блоке **Create album** — можно описать содержимое по-русски в поле «AI description» и нажать **Generate**: AI придумает ID и название.
2. Проверь/поправь поля **Album ID** (формат `2025.06.01-слово-слово-слово`) и **Title**.
3. Поле **Secret** можно оставить пустым — сгенерируется автоматически.
4. Нажми **Create**.

Ссылка для просмотра: `https://your-domain/<albumId>#<secret>`

### Изменить название или секрет

В списке альбомов найди нужный → **Edit** → измени **Title** или **Secrets** → **Save**.

### Переименовать ID

В строке альбома → поле **rename** → **Save**. Фото в хранилище не переезжают: альбом это только список ссылок, переименование мгновенное. Старая ссылка перестаёт работать сразу.

### Удалить

В строке альбома → **Delete**. Удаляется только сам альбом (`info.json`). Фото остаются в общем хранилище, потому что могут использоваться другими альбомами. Освободить место: **GC orphans** (см. ниже).

## Фотографии

### Порядок

Фотографии отображаются **в алфавитном порядке имён файлов**. Чтобы управлять порядком — называй файлы с числовым префиксом:

```
001_beach.jpg
002_sunset.jpg
010_dinner.jpg
```

### Загрузить

В карточке альбома → выбери один или несколько файлов (любой формат картинки) → **Upload**.

Браузер считает SHA-256 исходного файла и спрашивает сервер, есть ли уже такое фото. Если есть (загружал раньше в этот или другой альбом) — конвертация и загрузка пропускаются, фото просто добавляется в альбом. Иначе браузер конвертирует файл в JPEG: оригинал до 3000px по длинной стороне и превью до 1000px. Готовить превью вручную не нужно.

Одно и то же фото в нескольких альбомах хранится один раз. Если файл с таким **именем** уже есть в альбоме, но это другое фото — включи **Overwrite** перед загрузкой.

### Собрать альбом из уже загруженных фото

В карточке альбома → блок **Add photos from another album** → выбери альбом-источник → **Load** → отметь фото (или **Select all**) → **Add selected**. Ничего не копируется, только добавляются ссылки. Так удобно делать из одной полной съёмки несколько подборок.

### Изменить порядок

Переименуй файл: карточка фото → **Rename** → введи новое имя (например, `005_beach.jpg`) → **OK**.  
Порядок пересчитывается автоматически.

### Удалить фото

Карточка фото → **Delete**. Фото убирается из этого альбома; в хранилище оно остаётся (может быть в других альбомах). Место освобождает **GC orphans**.

## Обслуживание хранилища

### GC orphans (освободить место)

Кнопка **GC orphans** над списком альбомов. Сначала сканирует хранилище (ничего не удаляя) и показывает, сколько фото не используется ни одним альбомом, затем спрашивает подтверждение и удаляет. Фото, загруженные меньше часа назад, не трогаются.

### Verify files

**Verify files** в карточке альбома проверяет, что все фото из списка существуют в хранилище; битые записи убираются, отсутствующие превью подсчитываются. **Verify files (all)** — то же для всех альбомов.
