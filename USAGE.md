# Как пользоваться OhMyPhoto

Открой `/admin.html` в браузере (локально: `http://127.0.0.1:8787/admin.html`, на проде: `https://your-domain/admin.html`).  
Введи `ADMIN_TOKEN` и нажми **Login**.

---

## Разделы (альбомы)

### Создать

1. В блоке **Create album** — можно описать содержимое по-русски в поле «AI description» и нажать **Generate**: AI придумает ID и название.
2. Проверь/поправь поля **Album ID** (формат `2025.06.01-слово-слово-слово`) и **Title**.
3. Поле **Secret** можно оставить пустым — сгенерируется автоматически.
4. Нажми **Create**.

Ссылка для просмотра: `https://your-domain/<albumId>#<secret>`

### Изменить название или секрет

В списке альбомов найди нужный → **Edit** → измени **Title** или **Secrets** → **Save**.

### Переименовать ID

В строке альбома → поле **rename** → **Save**. Файлы переезжают в R2 пачками (по 200 объектов на запрос), админка сама повторяет запрос до конца и показывает прогресс. Если процесс прервался (закрыл вкладку) — просто нажми **Save** с тем же новым ID ещё раз, перенос продолжится. Старый ID перестаёт работать только после завершения.

### Удалить

**Edit** → **Delete album**. Удаляются все файлы (фото + превью + info.json).

## Фотографии

### Порядок

Фотографии отображаются **в алфавитном порядке имён файлов**. Чтобы управлять порядком — называй файлы с числовым префиксом:

```
001_beach.jpg
002_sunset.jpg
010_dinner.jpg
```

### Загрузить

В карточке альбома → выбери один или несколько файлов (любой формат картинки) → **Upload**.

Браузер сам конвертирует каждый файл в JPEG: оригинал до 3000px по длинной стороне и превью до 1000px. Готовить превью вручную не нужно. Сервер принимает только JPEG (проверяет сигнатуру файла), поэтому заливать напрямую в R2 нужно тоже `.jpg`.

Если файл с таким именем уже есть — включи **Overwrite** перед загрузкой.

### Изменить порядок

Переименуй файл: карточка фото → **Rename** → введи новое имя (например, `005_beach.jpg`) → **OK**.  
Порядок пересчитывается автоматически.

### Удалить фото

Карточка фото → **Delete**. Удаляются оригинал и превью, имя убирается из списка альбома.

### Синхронизировать список (если заливал файлы напрямую в R2)

Если ты загрузил файлы в `albums/<albumId>/photos/` прямо через Wrangler или S3-консоль — нажми **Rebuild files list** в карточке альбома. Список в `info.json` обновится по содержимому бакета.
