# Как пользоваться OhMyPhoto

Открой `/admin` в браузере (локально: `http://127.0.0.1:8787/admin.html`, на проде: `https://your-domain/admin`).  
Пока не залогинен, видна только форма входа: введи `ADMIN_TOKEN` и нажми **Log in**. Сессия живёт 7 дней; **Log out** в правом верхнем углу.

Админка состоит из страниц: список альбомов (**Albums**), страница альбома, **New album** и **Trash**. Кнопки «назад/вперёд» браузера переключают страницы, ссылку на страницу альбома (`/admin#/album/<albumId>`) можно сохранить в закладки.

---

## Разделы (альбомы)

### Создать

1. Нажми **New album** над списком. Можно описать содержимое по-русски в первом поле и нажать **Generate**: AI придумает ID и название.
2. Проверь/поправь поля **Album ID** (формат `2025.06.01-слово-слово-слово`) и **Title**.
3. Поле **Secret** можно оставить пустым — сгенерируется автоматически (20 символов). Свой секрет должен быть не короче 16 символов: он же подписывает ссылки на фото, короткий секрет можно подобрать по одной утёкшей ссылке на картинку.
4. Нажми **Create album** — откроется страница нового альбома.

Ссылка для просмотра: `https://your-domain/<albumId>#<secret>`. На странице альбома в блоке **Share** есть ссылка **open**, кнопка **copy link** и QR-код (скачивается как PNG или SVG); в списке альбомов — те же **open** и **QR**.

### Изменить название или секрет

Открой альбом (клик по строке или **Manage**) → блок **Settings** → измени **Title** или **Secrets** (по одному в строке) → **Save**. Кнопка **+ generated secret** добавляет новый случайный секрет: удобно для ротации — добавь новый, разошли новую ссылку, потом удали старый. Старые короткие секреты помечаются как weak; они продолжают работать, но лучше заменить.

### Переименовать ID

На странице альбома → **Settings** → поле **Rename album ID** → **Save**. Страница сразу переключается на новый ID. Фото в хранилище не переезжают: альбом это только список ссылок, переименование мгновенное. Старая ссылка перестаёт работать сразу.

### Удалить и восстановить

На странице альбома → блок **Delete album** внизу. Сам альбом (`info.json`) переезжает в корзину, фото остаются в общем хранилище, потому что могут использоваться другими альбомами. Освободить место: **GC orphans** (см. ниже).

Ссылка **Trash** в верхней панели показывает удалённые альбомы: **Restore** возвращает альбом (можно под новым ID в поле «restore as»), **Delete forever** удаляет запись из корзины. Если после удаления альбома запускался GC, часть его фото могла быть удалена — после восстановления нажми **Verify files**, битые записи уберутся.

## Фотографии

### Порядок

Фотографии отображаются **по имени файла в естественном порядке**: `2.jpg` идёт перед `10.jpg`, нули впереди не нужны. Чтобы управлять порядком — называй файлы с числовым префиксом:

```
1_beach.jpg
2_sunset.jpg
10_dinner.jpg
```

### Загрузить

На странице альбома → блок **Photos** → выбери один или несколько файлов (любой формат картинки) или перетащи их в рамку → **Upload**.

Браузер считает SHA-256 исходного файла и спрашивает сервер, есть ли уже такое фото. Если есть (загружал раньше в этот или другой альбом) — конвертация и загрузка пропускаются, фото просто добавляется в альбом. Иначе браузер конвертирует файл в JPEG: оригинал до 3000px по длинной стороне и превью до 1000px. Готовить превью вручную не нужно.

Одно и то же фото в нескольких альбомах хранится один раз. Если файл с таким **именем** уже есть в альбоме, но это другое фото — включи **overwrite existing names** перед загрузкой.

Если какой-то файл не загрузился (например, HEIC с iPhone в Chrome или обрыв связи), остальные всё равно загружаются; в конце показывается список неудавшихся файлов с причиной. Переименование и удаление во втором окне админки безопасно: изменения не перетирают друг друга.

### Собрать альбом из уже загруженных фото

На странице альбома → раскрой **Add photos from another album** под формой загрузки → выбери альбом-источник → **Load** → отметь фото (или **Select all**) → **Add selected**. Ничего не копируется, только добавляются ссылки. Так удобно делать из одной полной съёмки несколько подборок.

### Изменить порядок

Переименуй файл: в карточке фото исправь имя (например, `005_beach.jpg`) и нажми **Rename** или Enter.  
Порядок пересчитывается автоматически.

### Удалить фото

Карточка фото → **Remove**. Фото убирается из этого альбома; в хранилище оно остаётся (может быть в других альбомах). Место освобождает **GC orphans**.

## Обслуживание хранилища

### GC orphans (освободить место)

Кнопка **GC orphans** над списком альбомов. Сначала собирает список фото, на которые ссылаются альбомы, затем сканирует хранилище (ничего не удаляя) и показывает, сколько фото не используется ни одним альбомом, спрашивает подтверждение и удаляет. Фото, загруженные меньше часа назад, не трогаются. Фото из альбомов в корзине **не** считаются используемыми.

### Verify files

**Verify files** на странице альбома проверяет, что все фото из списка существуют в хранилище; битые и устаревшие записи (например, из старого формата хранения, где в списке были только имена файлов) убираются и показываются как `invalid`, отсутствующие превью подсчитываются, размеры файлов записываются. Большие альбомы проверяются порциями по 20 фото, прогресс виден в статусе. Счётчик **Photos** в списке после этого совпадает с тем, что видит галерея. **Verify files (all)** над списком альбомов — то же для всех альбомов по очереди.

## Что видит клиент

Сетка превью; клик открывает просмотр с кнопками, стрелками на клавиатуре и свайпом на телефоне. Внизу показывается номер фото (`3 / 42`), имя файла и ссылка **Download**, которая сохраняет оригинал под его именем. Если клиент потерял часть ссылки после `#`, галерея объясняет по-человечески, что ввести, и просит обратиться к фотографу за новой ссылкой.

## Скачивание альбома архивом (для клиентов)

Над сеткой фото в галерее есть кнопка **Download all as ZIP**. Архив собирается прямо в браузере клиента из оригиналов, сервер его не готовит.

Ограничения: не больше **100 фото** и не больше **500 МБ** оригиналов в альбоме. Если альбом больше, кнопка остаётся видимой, но при нажатии клиент видит сообщение, какое именно ограничение превышено. Для больших съёмок делайте отдельный альбом с избранным (**Add from another album**) или делите съёмку на несколько альбомов.

Если в галерее написано, что размеры фото не записаны (альбомы, загруженные до появления этой функции), нажмите **Verify files** для этого альбома (или **Verify files (all)**) — после этого кнопка заработает.
